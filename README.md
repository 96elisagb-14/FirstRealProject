# Practice Exercise Files

This folder contains three starter files like the example screenshot:

- `data.xlsx` — SAMPLE(EXAMPLE) Excel workbook with sales data, formulas, a summary sheet, and exercise prompts.
- `script.py` — Python practice script that reads the workbook and prints basic analysis.
- `README.md` — these instructions.

## Practice tasks

1. Open `data.xlsx` and review the `SalesData`, `Summary`, and `Exercises` sheets.
2. Run the script:
   ```bash
   python script.py
   ```
3. Modify the script to answer these questions:
   - Which region has the highest total revenue?
   - Which product has the highest average units sold?
   - How many rows did not meet the target?
4. Save your changes and rerun the script.

## Optional challenge

Add a new column in the Excel file called `Discounted Revenue` and update `script.py` to calculate total discounted revenue after a 10% discount.
